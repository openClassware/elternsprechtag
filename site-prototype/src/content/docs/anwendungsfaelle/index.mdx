import { LinkCard, CardGrid, Badge, Aside } from '@astrojs/starlight/components';

<Aside type="caution" title="Prototyp">
Ausschnitt des Katalogs: zwei Phasen, in **zwei Kartenformen** zum Vergleich. Nur „Einen Sprechtag
absagen“ führt auf eine ausgearbeitete Seite.
</Aside>

Jede Seite beschreibt **eine** Aufgabe, vom Anlass bis zu dem, was danach passiert. Wenn nicht anders
gekennzeichnet, erledigt sie der **Organisator** — in der Regel das Sekretariat.
